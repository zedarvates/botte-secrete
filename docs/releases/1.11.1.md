# Botte Secrète 1.11.1

Livraison corrective officielle préparée le 31 octobre 2026 à partir du commit
`d5139c08090d49d4eefa9eb43f303704275af710` de la livraison 1.11.0, avec les
modifications locales liées par le manifeste SHA-256 de cette livraison.

## Corrections

- Le plugin Codex annonce le catalogue complet avec `BOTTE_MCP_LAZY_TOOLS=0`.
  Les outils spécialisés sont directement enregistrés dans Codex, sans client
  MCP supplémentaire. Le mode compact du runtime reste disponible aux autres
  clients ; le texte de `find_tool` ne vaut pas enregistrement de méthode.
- Une régression démarre le vrai processus avec l'environnement déclaré dans le
  plugin et vérifie tous les outils et schémas avant les appels. Les sondes
  de runtime installé et d'hôte Codex vérifient les méthodes directement offertes.

- Les deux liens locaux du README du plugin visent des guides inclus dans le
  plugin : périmètre de validation et diagnostic MCP. Ils restent utilisables
  dans le ZIP marketplace seul et après copie du sous-dossier du plugin.
- Le README distingue la préparation de cette livraison 1.11.1 des recettes
  pour un candidat historique, d'une publication et d'une installation active.
- Le contrôle de distribution vérifie les liens Markdown de tout le plugin
  contre son propre périmètre, sans dépendre des documents du dépôt parent.
- Le runtime Python, le manifeste du plugin et les instructions du skill
  portent la version 1.11.1. Aucun algorithme du runtime n'est modifié.

## Vérification et statut

Les archives, leurs inventaires et les empreintes exactes sont décrits dans
`release-manifest.json`, `source-files.json`, `VALIDATION.json` et
`SHA256SUMS.txt` du dossier de livraison 1.11.1. Les tests et leurs limites sont
ceux de cette livraison ; les preuves historiques 1.11.0 ne sont pas présentées
comme de nouveaux essais 1.11.1.

Les archives et preuves 1.11.0 sont conservées. La publication GitHub et
l’installation officielle sont liées aux empreintes de cette livraison ; leurs
reçus d’exécution sont distincts des manifestes historiques de préparation.

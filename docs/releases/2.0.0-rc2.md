# Botte Secrète 2.0.0rc2

Bounded external-pilot candidate based on immutable RC1 commit
`d98505fd6586ff3d0d32a2cb4ebd5f0408d4142a`.

## Changes from RC1

- Backport #126: nonzero test-process status overrides passing-looking output;
  five real-process regression cases cover the persisted verdict.
- Backport #127: exact cache identity preserves whitespace and rejects ambiguous
  legacy keys; six regression cases cover persistence and recaching.
- Portable Python subprocess fixtures replace echo/false in sandbox tests.
- Candidate wheel installation and full-suite validation on Windows and Ubuntu
  with Python 3.12. CI records candidate tree and wheel SHA-256.

## Reproduce

The Release Candidate workflow must pass on the candidate tree before release.
Use a fresh virtual environment and a checkout at the published RC2 commit:

```bash
python -m pip wheel --no-deps --wheel-dir dist .
python -m pip install dist/botte_secrete-2.0.0rc2-py3-none-any.whl
python -I scripts/rc2_installed_smoke.py
python scripts/run_tests.py -q
python scripts/test_readme_commands.py
python scripts/check_docs_links.py
```

See the GitHub release notes for the exact commit and validation run. Build
tooling and dependency availability remain external. README badges retain the
stable version 1.9.0.

## Limits retained

Use observe, consultative or shadow mode. This is not production certification.
No independent human pilot review or genuinely private/external holdout is
established by these checks. The public slugify pilot remains RC1 evidence;
it has not been rerun for RC2. Other open feature branches are not incorporated.

RC1 and its historical reports remain unchanged. Read the
[pilot protocol](../external-pilot-protocol.md) and
[RC1 limitations](2.0.0-rc1-external-pilot.md).

# Botte Secrète 1.11.0

Livraison stable locale préparée le 31 octobre 2026 depuis `main`
`1ca0f7a7da7f6d15d231774c9a11719ca90830f1`, avec les corrections ci-dessous.
Les résultats exacts, plateformes et empreintes sont consignés dans le dossier
de livraison ; ce document ne remplace pas ces preuves. Publication distante
et remplacement d'une installation existante sont des opérations distinctes.

## Contenu

- Parcimonia : évaluation consultative, recherche GitHub bornée, outils de
  statistiques, doublons, liens et contexte de code.
- Runtime MCP, plugin Codex et catalogue Git cohérents en version 1.11.0.
- Factory Assurance, Memory Hub et contrats de preuve déjà intégrés à `main`.
- Cache persistant : transactions coopératives entre processus et threads,
  lectures rafraîchies, effacement et expiration durables, comptage cohérent.
  Les options de supervision sémantique et les empreintes de contexte restent
  disponibles. Une ancienne version du cache ne participe pas au nouveau verrou.
- Windows : lectures de preuves après réécriture, observations de fichiers et
  verrou de superviseur corrigés. Les comparaisons de métadonnées restent
  complètes entre deux observations provenant de la même API.
- Tests portables : octets des fixtures explicites, chemins POSIX normalisés,
  sous-processus Python et fermeture effective des connexions SQLite de test.

## Installation

Utiliser le wheel et les empreintes du dossier de livraison. Créer un
environnement virtuel dédié, puis installer le fichier local :

```text
python -m venv .venv-botte
<python-de-la-venv> -m pip install <chemin>/botte_secrete-1.11.0-py3-none-any.whl
<python-de-la-venv> -m pip check
<botte-de-la-venv> version
```

Le wheel déclare ses dépendances Python ; leur installation peut nécessiter un
index ou un cache disponible. Le plugin nécessite séparément `botte-mcp` sur
le PATH. L'archive de sources fournit le catalogue et le plugin ; aucune
configuration privée, donnée utilisateur ni poids de modèle n'est installé.

## Périmètre des preuves

Les tests logiciels, le dialogue MCP stdio, la qualification d'un hôte Codex et
un pilote indépendant sont des preuves distinctes. Aucun test de fixtures ne
prouve un gain global de qualité, de tokens facturés ou de coût. Les compteurs
du cache utilisent les valeurs fournies par l'appelant. Les politiques apprises
et routes expérimentales conservent leurs conditions d'activation existantes.

Pour revenir en arrière, conserver l'environnement actif et ses données ; cette
livraison est préparée et testée dans des environnements séparés.
